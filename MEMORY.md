## Important coding conventions

### CSS

- Modify existing rules rather than stacking override blocks.
- Remove obsolete duplicate rules after confirming the replacement.
- Reduce unnecessary `!important` usage.
- Do not alter approved desktop behavior when solving a mobile-only bug.
- Responsive fixes should go in the relevant existing media query where practical.
- Do not use `overflow-x: hidden` as a band-aid for unidentified layout problems.

### JavaScript

- Inspect current file before giving a full replacement.
- Avoid duplicate helper/functions.
- Shared public navigation: `frontend/js/main.js`.
- Public Services behavior: `frontend/js/services.js`.
- Dynamic service detail behavior: `frontend/js/service-detail.js`.
- Homepage interactions: `frontend/js/home.js`.
- Production admin logic: `frontend/admin.js`.
- `frontend/js/admin.js` is an older implementation and is not loaded by the current admin page.
- API wrapper: `frontend/js/api.js`.

## SEO decisions already established

- Public canonical domain is HTTPS.
- Prefer extensionless Cloudflare Pages URLs.
- `robots.txt` and `sitemap.xml` exist.
- Admin/auth/utility pages should not be indexed.
- `index-backup.html` should not be indexed.

- Klinik Putrijaya `P` mark is intended for favicon usage.
